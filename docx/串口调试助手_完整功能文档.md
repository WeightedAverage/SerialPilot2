# 串口调试助手 v4.0.0 — 完整功能文档

## 一、软件概述

基于 PyQt5 + pyserial 的双串口调试工具，深色主题，支持同时连接两个串口、分屏查看数据。窗口最小尺寸 1500×950。

**技术栈：** Python 3.8+ / PyQt5 / pyserial

**模块架构：**

```
main.py（入口）
 └─ MainWindow (project/main_window.py) — UI + 业务逻辑 (~1500行)
     ├─ SerialManager (project/serial_manager.py) — pyserial 封装
     │   └─ SerialThread (project/serial_thread.py) — QThread 后台读取线程
     ├─ DataLogger (project/data_logger.py) — 文件保存逻辑
     └─ AppLogger (project/logger.py) — 单例旋转日志系统 (logs/)
```

### 3.4 接收区（中间面板，左右分屏）

- 使用 `QSplitter(Qt::Horizontal)` 水平分割，可拖拽调整比例，默认 50:50
- 每个接收区独立，各含以下组件：

**接收区组件：**

| 组件 | 说明 |
|------|------|
| 标题标签 | `串口1 接收` / `串口2 接收`，青色 `#00CED1`，14px 加粗 |
| 暂停按钮 | QPushButton(checkable)，点击切换 暂停/继续，暂停时变红 |
| 清空按钮 | 清空接收区文本和缓冲区 |
| 自动滚动按钮 | QPushButton(checkable)，蓝色，与共享 checkbox 同步 |
| 导出按钮 | 弹出文件保存对话框，导出为 `.txt` |
| 接收文本框 | QTextEdit(只读)，Consolas 字体，深黑背景 `#080808`，绿色文字 `#00FF00` |

**接收区文字颜色规则：**

| 内容类型 | 颜色 | 示例 |
|----------|------|------|
| 时间戳 | 青色 `#00CED1` | `[14:30:05.123]` |
| 接收数据 | 绿色 `#00FF00` | `Hello World` |
| 发送数据 | 金色 `#FFD700` | `[14:30:05.123] SEND: AT+RST` |

**接收区高级特性：**

- **最大行数**：5000 行，超出自动删除前 2500 行
- **Ctrl+滚轮缩放**：字体 6pt ~ 36pt，默认 12pt，两个接收区同步缩放
- **智能日志行分割**：识别 `}` 后的 `[` 和时间戳格式自动换行
- **数据合并缓冲**：30ms 内的碎片数据合并后统一显示（QTimer::singleShot）
- **用户滚动检测**：监听滚动条位置，用户手动滚动时暂停自动滚动，鼠标离开接收区后恢复

**接收数据解析流程：**

```
原始 bytes → 接收缓冲区(bytearray)
  ↓ 30ms 合并定时器触发
  ↓ flush_recv_buffer()
  ├─ 十六进制显示模式? → data.hex(' ').upper()
  └─ 按编码解码(失败则回退HEX)
       ↓
     按行分割(_split_log_lines)
       ↓
     逐行添加时间戳 → append_to_receive()
       ↓
     QTextCursor 设置颜色格式写入
```

|------|------|
| `Enter` | 发送数据 |

**发送历史：**
- 最多保留 15 条记录
- 自动去重（相同内容不重复添加）
- 后进先出（最新在最上方）

**发送数据处理流程：**

```
输入文本
  ├─ HEX模式? → parse_hex_string() → bytes
  └─ 文本模式? → text.encode(encoding) → bytes
       ↓
  拼接换行符(CRLF/LF/CR/无)
       ↓
  serial_manager.send_data(bytes)
       ↓
  记录历史 + 显示在接收区(金色) + 更新统计
```

## 四、定时发送功能

定时发送通过 `SerialThread` 内部实现，不在主线程操作：

```cpp
// SerialThread::run() 伪代码
while (running) {
    data = serial_manager->readData();
    if (!data.isEmpty())
        emit dataReceived(data);

    if (timerEnabled && !timerData.isEmpty()) {
        if (currentTime - lastTimerTime >= timerInterval) {
            serial_manager->sendData(timerData);
            lastTimerTime = currentTime;
        }
    }
    msleep(5);  // 5ms 循环间隔
}
```

- 切换目标串口或关闭串口时自动停止定时发送
- 定时器参数通过 `set_timer(enabled, interval_ms, data)` 传入线程

## 八、日志系统

**AppLogger** — 单例模式，支持：

- 按日期命名日志文件：`assistant_YYYYMMDD.log`
- 轮转策略：单文件最大 10MB，保留 5 个备份

- 格式：`YYYY-MM-DD HH:MM:SS | LEVEL    | SerialAssistant | 消息`

- 串口事件：`[串口:COM3] 发送: 5 bytes | 数据: 48 65 6C 6C 6F`

## 九、错误处理策略

| 场景 | 处理方式 |
|------|----------|
| 串口打开失败 | 弹出 QMessageBox 警告 + 状态栏红色提示 |
| 串口读取连续错误 | 10 次连续错误后自动停止读取线程 |
| 串口意外断开 | 自动关闭连接 + 状态栏橙色提示 |
| 发送超时 | 捕获 `SerialTimeoutException`，弹出警告 |
| 配置加载失败 | 跳过，使用默认值，日志记录警告 |
| 编码解码失败 | 回退为十六进制显示 |
| HEX 格式错误 | 弹出 "HEX格式错误" 警告 |

## 十、Qt (C++) 复刻要点

### 关键实现细节

| 功能 | Qt 实现方案 |
|------|-------------|
| 双串口 | 两个独立的 `QSerialPort` + `QThread` 实例 |
| 分屏接收区 | `QSplitter(Qt::Horizontal)` 包裹两个 QWidget |
| 左侧面板 | `QScrollArea` 包裹，`setFixedWidth(330)` |
| 接收缓冲合并 | `QTimer::singleShot(30, ...)` 实现碎片合并 |
| Ctrl+滚轮缩放 | 重写 `eventFilter()`，拦截 `QEvent::Wheel`，检查 `Qt::ControlModifier` |
| 自动滚动检测 | 监听 `QScrollBar::valueChanged`，判断是否在底部 95% |
| 行数限制 | `QTextDocument::blockCount()` 超过 5000 时删除前 2500 行 |
| 彩色文本 | `QTextCursor` + `QTextCharFormat` 设置 `setForeground()` |
| 定时发送 | 在读取线程 `run()` 循环中检查间隔并调用 `write()` |
| 信号线状态 | `QSerialPort::pinoutSignals()` 轮询 DCD/DSR/CTS/RI/RTS/DTR |
| 配置持久化 | `QJsonDocument` 读写 JSON 文件 |

### 核心类设计建议

```cpp
// 建议的 C++ 类结构
class SerialManager : public QObject {
    Q_OBJECT
signals:
    void errorOccurred(const QString &msg);
    void dataSent(const QByteArray &data);
public slots:
    bool openPort(...);
    void closePort();
    bool sendData(const QByteArray &data);
    QByteArray readData();
};

class SerialThread : public QThread {
    Q_OBJECT
signals:
    void dataReceived(const QByteArray &data);
    void errorOccurred(const QString &msg);
    void connectionLost();
protected:
    void run() override;
};

class DataLogger : public QObject {
    Q_OBJECT
signals:
    void saveStatus(const QString &msg, bool success);
};

class MainWindow : public QMainWindow {
    Q_OBJECT
    // 双串口管理器
    SerialManager *serialManager1, *serialManager2;
    SerialThread  *serialThread1,  *serialThread2;
    DataLogger    *dataLogger;
    // UI 控件指针...
};
```

### 线程安全注意事项

- `SerialThread` 通过信号传递数据到主线程，**绝不直接操作 UI**
- `SerialManager` 的读写方法在子线程调用，需确保 `QSerialPort` 实例不跨线程
- 建议每个 `SerialThread` 持有自己的 `SerialManager` 实例，或使用 `moveToThread()`

## 十一、换行符映射表

| 名称 | 字节值 | 说明 |
|------|--------|------|
| CRLF | `\r\n` (0x0D 0x0A) | Windows 标准 |
| LF | `\n` (0x0A) | Linux/macOS |
| CR | `\r` (0x0D) | 旧版 Mac |
| 无 | 空 | 不追加换行 |
